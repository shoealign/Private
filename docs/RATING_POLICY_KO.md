# BALBOLL 51개 모델 평가 기준 (2026-10-14)

- 51개 전 모델에 데일리, 장거리, 템포런, 쿠셔닝, 안정성의 100점 척도 편집 추정치를 입력했습니다.
- 종합점수는 5개 항목 단순 평균입니다.
- 기존 26개 모델은 기존 임시 점수를 소폭 보정했고, 25개 미평가 모델은 원본 제품 특성/장단점/카테고리를 근거로 신규 편집 추정치를 작성했습니다.
- RunRepeat의 공개된 평가 체계 및 대표 모델(예: Novablast 5)을 참고했지만 51개 모델의 RunRepeat 실측값을 일괄 수집·검증한 것은 아니며, 점수를 그대로 옮기지 않았습니다.
- 따라서 이 수치는 RunRepeat 평점, 실험실 측정값, 검증된 사용자 평균이 아닌 BALBOLL의 임시 평가입니다.
- 서로 다른 사용 목적을 20%씩 평균하므로 레이싱화 등 특화 제품의 종합점수는 상대적으로 낮을 수 있습니다.
