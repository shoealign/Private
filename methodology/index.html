HOW TO READ SHOELINEUP

점수와 자료를 읽는 방법

SHOELINEUP은 러닝화 정보를 모아 비교하는 서비스입니다. 직접 실험한 기관이나 모든 원문을 재검증한 구매후기 서비스로 표시하지 않습니다.

LINEUP SCORE와 MATCH는 다릅니다

LINEUP SCORE: 이전 버전에 수록된 참고 점수입니다. 원문 점수 → 정규화 → 가중치 계산을 재현할 자료가 아직 없어 산식 검증 전으로 표시합니다. 전문기관의 실험값, 검증된 구매자 평균, 모든 러너에게 통용되는 성능 순위를 뜻하지 않습니다. 소수 둘째 자리는 표시 형식일 뿐 검증 정밀도가 아닙니다.

점수 순에서는 카테고리가 달라져도 동일한 수록 점수로 정렬합니다. 평가가 없는 제품을 0점 제품으로 취급하거나 임의 점수를 만들지 않습니다. 광고·구매처 버튼 클릭은 점수에 반영하지 않습니다.

MATCH: 입력 조건과 수록 분류의 일치 점수입니다. (발볼 일치 × 30 + 사용 목적 × 30 + 거리 × 20 + 경험 × 20) ÷ 반영 가중치 합으로 계산하며 자료가 없는 항목은 가중치에서 제외합니다. 착화 성공 확률이나 추천 정확도 검증 수치가 아닙니다.

케이던스 수치만으로 SKY/EDGE 또는 숙련도를 결정하지 않습니다. 성별·컬러·사이즈·체중·페이스·주간거리·선호 요소는 참고 입력으로 저장하며 해당 속성과 제품 SKU 간 검증된 연결이 없는 현재 버전에서는 MATCH에 직접 가산하지 않습니다. ‘잘 모르겠어요’를 선택했다고 감점하지 않습니다.

리뷰 건수는 무엇을 세나요?

수록된 개별 리뷰 원문 URL을 중복 제거해 셉니다. 전문 리뷰와 Reddit·블로그·영상 사용 경험을 구분하고, 공식 발표·제품 페이지·검색 결과는 별도 자료로 표시합니다. 링크 1개가 구매자 1명이나 레이스 1회를 의미하지 않습니다.

이번에 재열람한 원문만 확인 날짜를 붙입니다. 기존 자료의 발표일·주행거리·협찬 정보가 현재 원문과 다를 수 있으며, 브랜드 이름이나 링크만으로 신뢰도 90점 같은 수치를 부여하지 않습니다.

발볼·거리·사이즈

표준 모델의 발볼 체감과 와이드 옵션 유무는 별도 항목입니다. 여러 리뷰의 기준 사이즈·측정 방식이 다르므로 실측 mm로 바꾸지 않습니다. 대회 거리만으로 자동 반업을 확정하거나 미확인 정보를 정사이즈로 채우지 않습니다.

이전 버전의 내구성 점수로 계산한 권장 교체 한도는 검증된 제품 수명이 아니므로 숨겼습니다. 원문의 누적 사용거리와 모델 보증 수명을 혼동하지 않습니다. 실제 대회 출전과 훈련 거리 테스트를 분리할 근거가 확보되기 전에는 레이스 횟수를 확정 집계하지 않습니다.

가격·출시일·이미지

발매가는 기존 수록 자료이며 현재 구매 가능한 가격이 아닙니다. KREAM 가격은 자동 수집하지 않고 상품 또는 모델 검색으로 연결합니다. 공식몰 링크도 ‘판매 중’으로 단정하지 않습니다. 한국 출시가 확인되지 않은 해외 일정은 한국 출시일로 바꾸지 않습니다.

제품 사진은 원본 이미지 주소를 사용합니다. 외부 서버가 차단하거나 파일을 삭제하면 대체 이미지가 표시될 수 있습니다. 모든 모델의 이미지 사용권·모델/색상 일치·현재 표시 상태가 확인된 것은 아닙니다.
